# YOLO & ByteTrack Stream Classification

Python project for YOLO object detection, ByteTrack tracking, and video/webcam/RTSP stream classification.

## Setup

1. Virtual Environment:
   ```bash
   # Windows PowerShell
   .\venv\Scripts\Activate.ps1
   ```

2. Install dependencies:
   ```bash
   pip install ultralytics opencv-python
   ```
